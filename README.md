# pdf bars

Локальный редактор PDF для Windows и RED OS. Объединяйте документы, меняйте
порядок страниц, исправляйте текст сканов и преобразуйте документы без загрузки
файлов в облачные сервисы. Телеметрии, сбора статистики и фоновой отправки отчётов нет.

## Возможности

- Объединение PDF и изображений, удаление, копирование, поворот и перестановка страниц.
- Обрезка, выравнивание сканов, разбиение длинных листов на A4/A3/A5, отмена правок.
- Добавление текста, замена слов с восстановлением фона, шрифт, цвет, жирный,
  курсив, подчёркивание и необязательный эффект сканирования.
- Рисование, линии и стрелки, закрытие областей, копирование фрагментов.
- Подписи с удалением фона и усилением контраста.
- Локальное OCR на русском и английском, поиск и выделение распознанного текста.
- PDF → редактируемый DOCX с распознаванием текста и таблиц; перенос графики по выбору.
- Изображения ↔ PDF, DOCX → PDF, сжатие и печать.
- Режим чтения, масштабирование и миниатюры страниц.

## Скачать

[Готовые выпуски для Windows и RED OS](https://github.com/andreymitinskii/pdf-bars/releases).
Windows 10/11 x64: распакуйте portable-архив или запустите установщик.
Windows-сборка не имеет цифровой подписи; Windows может показать предупреждение
о неизвестном издателе. Сверьте SHA256SUMS.txt. RED OS: установите
RPM командой `sudo dnf install ./pdf-bars-1.7-1.x86_64.rpm`.

## Запуск из исходников

Требуется Python 3.8+ и Tk. На Linux установите python3-tkinter, Ghostscript и
клиент CUPS. Для DOCX → PDF нужен установленный Microsoft Word на Windows
или Р7-Офис на Linux; эти программы не входят в комплект.

```sh
python -m pip install -e .
pdf-bars-gui
```

OCR-модели включены. DOCX после OCR может потребовать ручной корректировки;
сохранение PDF/A после редактирования не гарантируется. Шрифты Microsoft и
офисные редакторы не распространяются с приложением.

## Сборка и проверка

```sh
python -m pip install -e . pytest
python -m pytest -q
sh scripts/build-wheelhouse.sh
sh scripts/build-redos-rpm.sh
```

Windows: `python -m pip install pyinstaller`, затем
`python -m PyInstaller packaging/windows/pdf-bars.spec --noconfirm`.
Установщик создаётся сценарием `scripts/build-windows.ps1`.
