# Third-party components

pdf bars uses PyMuPDF/MuPDF (GNU AGPL v3; commercial alternatives exist),
pypdf (BSD-3-Clause), Pillow (HPND), tkinterdnd2/TkDnD (their included BSD-style
licenses), typing_extensions (PSF), Python and Tcl/Tk (their included licenses).
PyInstaller's bootloader has an exception permitting redistribution of frozen
applications; its bundled license files are retained.

Tesseract language data rus/eng is distributed under Apache-2.0; see
src/redos_pdf_combiner/assets/tessdata/LICENSE and SOURCE.txt. The OCR engine
is provided by the installed PyMuPDF build. Full dependency metadata and license
files are included with vendored modules. Corresponding pdf bars source code is
published with each release. No Microsoft fonts, Microsoft Word, R7 binaries,
corporate logos, or proprietary sample documents are included.
