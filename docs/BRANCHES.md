# Release Lines

This repository and checkout contain the public `release/1.7` line only.
Application version: 1.7.2. RPM package: `pdf-bars`. Configuration, the
signature library and cache use `pdf-bars-public` on Linux and `PDFBarsPublic`
on Windows.

The corporate 1.6 line is a separate repository and checkout:
`C:\Project\pdf-bars-1.6`, branch `release/1.6`, package `redos-pdf-bars`.
Do not copy corporate configuration, assets, reporting or contacts here.
Build and publish the two lines independently. The packages are exclusive;
switching editions must be an explicit administrative action.

Earlier locally generated public RPMs labelled 1.6.1-1/2 were misidentified.
They are superseded by the correctly identified corporate migration release;
they must not be reused as the corporate update or published as that branch.
