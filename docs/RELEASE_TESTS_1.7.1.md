# pdf bars 1.7.1: проверка выпуска

Дата: 16 ноября 2026 года.

## Изменения

- Английский и русский интерфейс. На русской системе автоматически выбирается
  русский; для остальных языков системы — английский. Язык можно сохранить в
  «О программе»; он применяется после перезапуска без сброса текущих правок.
- Язык OCR независим от интерфейса; текст документов и имена файлов не переводятся.
- Полностью удалено окно «Что нового». В «О программе» добавлены данные
  разработчика: Митинский А.А., andreymitinskii@gmail.com.
- Windows: основной режим — для всех пользователей в Program Files с запросом
  администратора. Общие ярлыки и регистрация Open With используют системный
  контекст, настройки приложения остаются отдельными для каждого пользователя.
- /CURRENTUSER включает персональную установку в LocalAppData/Programs без
  администратора. Старый путь не подхватывается автоматически. Попытка выбрать
  защищённую папку без повышения прав отклоняется с понятным сообщением; тихая
  установка не зависает на диалоге и возвращает ненулевой код завершения.
- Включены русское и английское руководства; открывается вариант на языке UI.

## Результаты

- Windows: 382 теста успешно. Проверены английские вкладки и панели на широком
  и компактном окне, смена языка и сохранение пользовательского текста.
- Готовый Windows-установщик собран Inno Setup. Персональная установка завершилась
  с кодом 0; установленный EXE совпал со сборкой. Встроенный selfcheck проходит
  с ru и en. Манифест приложения asInvoker: работа программы не требует повышения.
- Проверка /CURRENTUSER с защищённым путём Program Files завершилась кодом 7
  и понятным сообщением до записи файлов, без зависания и изменения ACL.
- Фактическая установка в режиме для всех пользователей с подтверждением UAC
  в автоматической проверке не выполнялась: терминал работает без администратора.
  Настройки системного контекста и запроса повышения проверены в сборочном
  сценарии и компилятором. Для общей установки потребуется подтверждение администратора.
- Один и тот же RPM обновлён на RED OS 7.3.6 / Python 3.8.20 и RED OS 8 /
  Python 3.11. На каждой системе: 380 тестов успешно, 2 Windows-теста пропущены.
  Включена проверка свежего английского интерфейса в отдельном процессе.
- Целостность RPM, встроенные зависимости и OCR-модели проверены; установленные
  Python-модули и английский словарь побайтно совпадают с исходниками.
- Оба руководства отрисованы и визуально проверены. Телеметрия не возвращалась.

## Ограничения

Windows-установщик и RPM не подписаны ключом издателя; сверяйте SHA256SUMS.txt.
Для общей установки и её обновления нужны права администратора; не предоставляйте
обычным пользователям право изменять файлы Program Files. При переходе с
персональной установки на общую рекомендуется предварительно удалить старую
персональную копию, чтобы старые личные ярлыки не перекрывали общие.
Прочие ограничения OCR, офисных конвертеров и редактирования PDF/A остаются прежними.
