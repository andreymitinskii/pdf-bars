# pdf bars 1.7: проверка открытого выпуска

Дата: 16 ноября 2026 года.

## Проверено

- Windows: 368 тестов успешно. Установщик Inno Setup установлен без прав
  администратора; проверены запуск приложения и встроенный selfcheck.
  Контрольные суммы установленного и собранного EXE совпадают.
- Один и тот же RPM установлен на RED OS 7.3.6 / Python 3.8.20 и RED OS 8 /
  Python 3.11. На каждой системе: 366 тестов успешно, 2 Windows-теста пропущены.
  Проверены встроенные зависимости, OCR-модели и целостность RPM.
- Установленные исходники на обеих RED OS побайтно совпадают с опубликованными.
- Проверены реальное OCR и создание DOCX, а также преобразование DOCX → PDF
  через Microsoft Word, Р7-Офис и LibreOffice. PDF результата открывается и
  имеет ожидаемое число страниц.
- Тесты резервного выбора конвертера покрывают отсутствие Word в Windows,
  ошибку основного движка, изоляцию незавершённых файлов, явный выбор soffice,
  сообщения об отсутствии офиса, прогресс пакета и защиту от перезаписи.
- GitHub Actions настроен на автоматический запуск тестов в Ubuntu.
- Из открытой версии удалены сборщик статистики, клиент отправки отчётов,
  конфигурация серверов, корпоративные ресурсы и прежние контакты. Проверка
  отсутствия сетевого кода приложения включена в регрессионные тесты.

## Ограничения

- ONLYOFFICE и OpenOffice обнаруживаются, но реальная конвертация именно в этих
  пакетах на тестовых машинах не проверена. Поддерживается их совместимый
  x2t/soffice-интерфейс, а не произвольная автоматизация любого офисного приложения.
- Office и шрифты Microsoft устанавливаются отдельно и не распространяются.
- У Windows-установщика нет цифровой подписи, RPM не подписан ключом издателя.
  Проверяйте SHA256SUMS.txt, загружайте файлы только из этого репозитория.
- Маскирование области не является безопасным удалением исходных данных;
  изображение подписи не является квалифицированной электронной подписью.
- После редактирования не гарантируется соответствие PDF/A. Сложные DOCX
  после OCR требуют визуальной проверки. Функция локальной диагностики не
  отправляет файл автоматически; перед передачей проверьте его содержимое.
