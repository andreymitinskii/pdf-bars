# Системные диалоги файлов в RED OS

В RED OS открытие, сохранение и выбор папки используют GTK-диалог,
привычный для рабочего стола MATE. Он подключён во всех разделах программы,
в том числе для подписей, экспорта и сохранения отладочной информации.

Сохраняются выбор нескольких файлов, фильтры форматов, начальная папка,
имя файла, выбранный формат и подтверждение перезаписи итогового файла.
Отмена закрывает диалог без запуска второго окна.

GTK 3 работает в отдельном процессе, не смешивается с Tk/GTK 4 и не
останавливает перерисовку главного окна. Пока диалог открыт, другие команды
главного окна недоступны. Если GTK запустить не удалось, используется Tk.
В Windows остаются прежние системные диалоги Tk.

Это описание относится к публичной ветке 1.7 (`pdf-bars`).
Корпоративные сборки не выпускаются из этого репозитория.
