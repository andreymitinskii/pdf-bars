# pdf bars 1.7.2: проверка выпуска

## Изменения

- Для RED OS: системные GTK/MATE-диалоги открытия, сохранения и выбора папки.
- Копирование областей в виде изображений в системный буфер обмена Windows
  и Linux. Сохраняются масштаб и возможность вставки внутри программы.
- Ярлыки обрабатываются идемпотентно; публичная версия не меняет корпоративные
  ярлыки и использует отдельный каталог для настроек, кэша и подписей.
  Подписи из прежнего общего каталога можно явно импортировать через интерфейс.
- Публичная ветка не вносит изменения в корпоративные исходники, репозиторий
  или сборщик. Телеметрии и корпоративных ресурсов в публичном выпуске нет.

## Проверки

| Среда | Результат |
| --- | --- |
| Windows x64, исходники | 404 теста прошли, 2 Linux-теста пропущены |
| RED OS 7.3.6, Python 3.8.20 | 403 теста прошли, 3 пропущены |
| RED OS 8, Python 3.11.11 | 403 теста прошли, 3 пропущены |

- Windows: собраны установщик Inno Setup и portable ZIP. Для EXE из ZIP
  проверены версия и встроенная самопроверка с русским и английским языком.
  Установщик для всех пользователей повторно не запускали.
- RED OS: обе ВМ проверены одним RPM с одинаковым SHA-256. Тесты и самопроверка
  запускались из распакованного RPM с отдельными настройками, без установки
  поверх корпоративной редакции. Проверены файлы пакета, OCR-модели,
  системные диалоги и копирование изображения в буфер.
- Пробная транзакция RPM на обеих ВМ подтвердила конфликт между редакциями.
  Установленные корпоративный клиент 1.6.1-3 и сборщик не изменились.
  Публичный RPM не обновляет корпоративный. Не применяйте принудительную
  замену и не смешивайте источники обновлений: корпоративный выпуск 1.6.1-3
  сам может заменять пакеты с именем `pdf-bars` по правилам своей миграции.
- Исходники публичного выпуска и его история проверены отдельно от
  корпоративного репозитория. Готовые файлы не входят в историю Git.

Пакеты не подписаны ключом издателя. Перед установкой сверяйте SHA-256.
